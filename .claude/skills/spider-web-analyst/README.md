# spider-web-analyst

A Claude skill for patient, precise systems analysis: mapping incentives,
dependencies, timing, risks, hidden pressures, weak links, and leverage
points before recommending action.

## Version

2.0.0

## Contents

- `SKILL.md` — skill definition, sequential thinking procedure, bidirectional
  data contracts, feedback loops, output formats, and ecosystem routing.

## What's new in v2

- **Sequential thinking procedure** — ten-step ST sequence with explicit
  conditional branching and mandatory ordering constraints.
- **Bidirectional skill contracts** — named inbound/outbound data contracts
  with alchemy-hive, boardgame-design-hydra, wargame-designer,
  adventure-design-skill, fiction-structure-engine, prose-style-voice-engine,
  military-gothic-voice, humanizer.
- **Feedback loop mechanism** — explicit positive/negative signal lists and
  a self-improvement rule to correct ordering errors across runs.
- **Domain-variant routing** — ST-1 classifies the request and selects the
  correct output format before any analysis begins.
- **Expanded trigger vocabulary** — description updated to cover more
  entry-point phrasings.

Upload the `.skill` file into Claude Skills where supported.
