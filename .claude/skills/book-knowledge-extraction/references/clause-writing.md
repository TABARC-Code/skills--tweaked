# Complex Clause Writing

Builds dense, precise, high-information writing without turning it into sludge.

Useful for: skill documents, technical explanation, academic prose, rules writing,
design documents, critical essays, structured prompts, argument development, procedural manuals.

Goal: controlled complexity. Sentences that carry more meaning, not sentences that merely look clever.

---

## Clause Types

Each clause must earn its place.

### Definition Clause
Defines a term or concept precisely.

> A reciprocal relationship contract is a structured record that explains how one skill affects another and how the affected skill records that influence in return.

Use when precision matters.

---

### Limiting Clause
Narrows the scope of a claim to prevent overclaiming.

> This link is strong when formatting determines the final output, but weak when formatting only affects presentation after the reasoning is complete.

Use to avoid overreach.

---

### Causal Clause
Explains why something happens.

> Because extraction changes the behaviour of downstream writing skills, the source skill must be recorded as an upstream influence.

Use when the reader needs the logic, not just the rule.

---

### Conditional Clause
Defines when a rule applies.

> If a sub-skill only activates for academic sources, its relationship weight must be contextual rather than strong.

Use for branching systems.

---

### Contrast Clause
Separates similar ideas.

> A summary reduces a source into a smaller text, whereas extraction converts the source into reusable knowledge.

Use to stop concepts blurring together.

---

### Exception Clause
Shows where the rule breaks or changes.

> Direct links are usually stronger than chain links, unless a distant upstream skill supplies a critical rule that governs execution.

Use to avoid brittle rules.

---

### Evidence Clause
Supplies support.

> The formatting skill should receive a strong dependency weight because the generated document's usability depends directly on layout, hierarchy, and readable structure.

Use when the system must justify its decision.

---

### Behavioural Impact Clause
Explains what changes in execution.

> When this relationship is active, the target skill must check source-derived definitions before generating new terminology.

Use to connect structure to behaviour.

---

### Audit Clause
Defines how compliance is checked.

> The link passes audit only if both sides contain matching relationship contracts with source, target, direction, strength, reason, and behavioural impact.

Use to make the system testable.

---

## Clause Assembly Pattern

A strong skill-writing sentence combines clauses in this order:

1. main rule
2. condition
3. reason
4. limitation
5. behavioural effect

Example:
> When a book-derived sub-skill changes how a writing skill selects evidence, the writing skill must record the sub-skill as a contextual upstream influence, because the effect only appears during evidence-heavy outputs, and the relationship should alter citation handling rather than general prose style.

## Domain Variants

Different skill domains demand different clause emphasis.

### Fiction and craft skills
Emphasise: behavioural impact, contrast, exception.
Reason: craft rules have legitimate exceptions; they govern sensibility more than procedure.

### Game design skills
Emphasise: conditional, evidence, audit.
Reason: game mechanics are falsifiable; rules must define when they fire and how they're tested.

### Technical / academic skills
Emphasise: definition, limiting, causal.
Reason: precise boundaries matter more than elegant expression.

### SEO and marketing skills
Emphasise: evidence, exception, behavioural impact.
Reason: persuasion systems depend on justification and real-world effect.

## Density Control

A sentence is too dense when:
- the main verb disappears under nouns
- every noun has three modifiers
- the reader has to restart the sentence
- the clause order hides the actual rule
- the sentence contains multiple unrelated actions

Repair by splitting into:
- rule sentence
- reason sentence
- example sentence
- audit sentence

---

## Knowledge Transfer Test

Weak:
> The source is useful for writing.

Stronger:
> The source should be linked to the writing skill as a moderate upstream influence because it supplies argument patterns, example structures, and phrasing constraints that affect drafting but do not control the full writing process.

If the clause cannot survive the question "what should happen differently because of this?" — rewrite it.
